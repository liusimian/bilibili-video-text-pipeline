# 视频总结模板（固定骨架，保证多期一致、少返工）

> 使用方式：只读同目录的 `摘要输入.md`，按下面骨架一次写成，不要回头再读原始 OCR 文件。

## 0. 视频档案
标题 / BV / UP主 / 时长 / 发布日期 / 数据（播放·点赞·投币·收藏·分享）

## 1. 一句话结论
用一句话说清"作者认为会发生什么、为什么"。

## 2. 核心论点链
3—6 条，每条一行，形成因果链（可从"制度性质 → 分配结构 → 历史债务 → 人口约束 → 政策推演"展开）。

## 3. 分段详解
按 `摘要输入.md` 的 5 分钟分块逐段展开：
- 【口播】该段讲了什么（保留全部论据、数字、文件号、比喻）
- 【画布】该段画面新出现的文字要点（条目化）
- 【关键数字】该段出现的数字单独列出

## 4. 关键数据表
| 主题 | 数据 | 口径/出处 |

## 5. 政策与文件清单
名称 + 文号 + 时间 + 要点

## 6. 概念词典
每个术语 1—2 行。

## 7. 论证结构图（纯文本）
用缩进箭头画出因果链，供模型直接引用。

## 8. 事实 vs 判断
分两栏：可核实的事实/数据；作者的个人判断、预测、命名（如"高溢价赎买"）。

## 9. OCR 不确定项
列出明显可能是识别错误、需要回看的数字或名词。

---
写作约束：
1. 不删减论据与数字；宁可长，不可漏。
2. 每个数字保留原始口径（作者口径 / 画布口径分别标注）。
3. 作者自创概念（如"滚动窗口期惩罚性追纳制"）原样保留并加引号。
4. 全文中文，Markdown，标题层级固定。
5. 篇幅参考：45 分钟视频约 1.5—2.5 万字；20 分钟约 0.8—1.2 万字。

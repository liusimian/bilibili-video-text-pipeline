# 推送与更新（本机）

这个文件夹（`github-export`）已经是仓库 `liusimian/bilibili-video-text-pipeline` 的本地副本，`origin` 指向 HTTPS 地址。

## 日常更新

```powershell
cd E:\Desktop\DS\视频\github-export
git add -A
git commit -m "update: 说明改了什么"
git push
```

认证由 Windows 凭据管理器提供（账号 `liusimian` 的 GitHub 凭据），不需要每次输入密码。

## 一键脚本

```powershell
powershell -ExecutionPolicy Bypass -File E:\Desktop\DS\视频\setup_git_push.ps1
```

等价于 `fetch` → 对齐远端 → `add/commit` → `push`，没有改动时会自动跳过提交。

## 视频为什么不在仓库里

- 原片 154 MB，超过 GitHub 单文件 100 MB 限制；
- 仓库根目录的 `.gitignore` 已排除 `*.mp4`、`half*/`、`shots/`、`cookies.txt`；
- 需要原片时用 BV 号重新下载即可（`scripts/video2text.py` 会自动处理）。

## 网络备注

`github.com` 在本机时通时不通（TLS 层会被重置）。如果 `git push` 报 `Failed to connect` 或 `Recv failure`：

1. 先 `Test-NetConnection github.com -Port 443` 看是否通；
2. 不通就用备用通道：本机已生成 SSH 密钥 `~/.ssh/id_ed25519_github`，把 `~/.ssh/id_ed25519_github.pub` 加到 GitHub 的 SSH keys 后，把 remote 换成
   `git@github.com:liusimian/bilibili-video-text-pipeline.git` 即可走 `ssh.github.com:443`；
3. 或者直接在另一台能访问 GitHub 的电脑上 `git clone` 后推送。
